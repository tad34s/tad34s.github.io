quickshell-bar privacy policy

quickshell-bar is a personal desktop status bar that shows its author's own Google Calendar events. It is not offered to anyone else.

Data accessed

The app requests read-only access to Google Calendar (https://www.googleapis.com/auth/calendar.readonly). It reads the list of calendars and the events in them: titles, times, locations, colours and links.

How the data is used and stored

Events are fetched directly from Google to the user's own computer and shown in the status bar. A cache of recent events and the login token are stored only on that computer. The data is not sent to any server, shared with anyone, sold, or used for advertising or any purpose other than displaying the calendar.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local data folder removes the cache and the token.
